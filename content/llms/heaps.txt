# Heaps API

> Heaps is a cross-platform 2D/3D game engine written in Haxe (targets: HashLink with SDL/OpenGL or DirectX, and JavaScript/WebGL). Packages: `h2d` (2D scene graph), `h3d` (3D engine, GPU abstraction), `hxd` (resources, input, system, sound), `hxsl` (Haxe shader language).

Each link points to the Markdown page of a type: signatures, documentation, inheritance and platform availability.
Full text of all the pages: https://jonathan-heteau.github.io/heaps-docs/llms/heaps-full.txt

## h3d

- [h3d.Buffer](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Buffer.md): A GPU buffer: vertex data (with the layout given by `format`), index data, or data read by shaders.
- [h3d.BufferFlag](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/BufferFlag.md): The flags of a `Buffer`, given at creation.
- [h3d.BufferHandle](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/BufferHandle.md): A bindless handle of a buffer, allowing shaders to access it without binding it.
- [h3d.Camera](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Camera.md): A 3D camera: a position `pos` looking at `target`, with a perspective (or orthographic, see `orthoBounds`) projection.
- [h3d.ColorAdjust](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/ColorAdjust.md): Color adjustments applied by `Matrix.adjustColor` (and `h2d.Drawable.adjustColor`).
- [h3d.DepthBinding](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/DepthBinding.md): How the depth buffer is bound when rendering to a target (see `Engine.pushTarget`).
- [h3d.Engine](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Engine.md): The 3D engine: it owns the graphics driver and the GPU memory manager, and manages the render targets and the frame.
- [h3d.GPUCounter](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/GPUCounter.md): A buffer of integer counters written by compute shaders and read back on the CPU.
- [h3d.IDrawable](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/IDrawable.md): Something which can be rendered by the engine, such as a `h3d.scene.Scene` or a `h2d.Scene` (see `hxd.App`).
- [h3d.Indexes](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Indexes.md): A GPU index buffer: the vertex indexes of the triangles of a primitive (16-bit, or 32-bit with `is32`).
- [h3d.Matrix](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Matrix.md): A 4x4 transformation matrix.
- [h3d.MatrixImpl](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/MatrixImpl.md): The implementation of `Matrix`: use `h3d.Matrix` instead.
- [h3d.Quat](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Quat.md): A quaternion representing a 3D rotation, used for instance by `h3d.scene.Object` to store its rotation.
- [h3d.Vector](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Vector.md): A 3 floats vector.
- [h3d.Vector4](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Vector4.md): A 4 floats vector.
- [h3d.Vector4Impl](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/Vector4Impl.md): A 4 floats vector.
- [h3d.VectorImpl](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/VectorImpl.md): A 3 floats vector.
- [h3d.anim.AnimatedObject](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/anim/AnimatedObject.md): An object animated by an `Animation`, identified by name, and its target once the animation is bound.
- [h3d.anim.Animation](https://jonathan-heteau.github.io/heaps-docs/api/heaps/h3d/anim/Animation.md): Base class of the animations: a set of animated objects (or joints) with keyframes, played on an object tree.
