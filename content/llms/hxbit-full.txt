# HxBit API (full text)

> HxBit is a binary serialization and network synchronization library for Haxe: classes implementing `hxbit.Serializable` get macro-generated, strictly typed serialization code; `hxbit.NetworkSerializable` objects are replicated by a `hxbit.NetworkHost` (property sync and RPCs). The README explains the concepts: [README.md](https://github.com/Jonathan-HETEAU/hxbit/blob/ccr-01f70725-tatboj/README.md).

# hxbit.Closure

Type parameters: `<T>`

Implements: [`hxbit.Serializable`](Serializable.md)

A serializable function, returning `T`: create it with `Closure.make(function() ...)`. The code is compiled in a generated class (in the `hxbit.closure` package) and the captured local variables are serialized with the closure, so it can be stored or sent and called later.

Creates a serializable closure from a function without arguments. The captured local variables (and `this`) must be serializable. `parentType` is the class to extend instead of `hxbit.Closure`.

## Methods


Calls the function, with the captured values.

### serialize

```haxe

```

### unserialize

```haxe

```
