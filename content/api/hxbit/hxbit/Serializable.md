# hxbit.Serializable

**interface** · package [`hxbit`](README.md) · source [`hxbit/Serializable.hx`](https://github.com/Jonathan-HETEAU/hxbit/blob/ccr-01f70725-tatboj/hxbit/Serializable.hx)

Extends: [`hxbit.AnySerializable`](AnySerializable.md)

Implemented by: [`hxbit.Closure`](Closure.md), [`hxbit.Schema`](Schema.md)

An object serialized by a `Serializer`: its fields marked with `@:s` are serialized, by code generated at compile time
(`hxbit.Macros.buildSerializable`). The fields of this interface are generated by the macro.

The constructor is not called when unserializing: the fields that are not serialized get their initial value
(`var x : Array<Int> = []`). Optional `customSerialize(ctx)` and `customUnserialize(ctx)` methods can (un)serialize
unsupported values.
