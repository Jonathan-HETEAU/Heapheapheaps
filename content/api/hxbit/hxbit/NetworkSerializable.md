# hxbit.NetworkSerializable

**interface** · package [`hxbit`](README.md) · source [`hxbit/NetworkSerializable.hx`](https://github.com/Jonathan-HETEAU/hxbit/blob/ccr-01f70725-tatboj/hxbit/NetworkSerializable.hx)

Extends: [`hxbit.ProxyHost`](ProxyHost.md)

A `Serializable` object that can be replicated over the network by a `NetworkHost`: its `@:s` fields are synchronized from
the authority to the clients, and its `@:rpc` methods are remote procedure calls (see the README for the RPC modes and
the `@:increment`, `@:condSend`, `@:notMutable`, `@:noSync`, `@:noSave` and `@:visible` field metadata).

The macro generates the fields of this interface, a `networkProp<Name>` constant for each field (see
`networkCancelProperty`) and `networkLocalChange(f)`, which runs `f` without sending the changes.
Set `enableReplication` to share the object: `alive` is then called on the clients when it is received.

## Methods

### alive

```haxe

```

Called on the clients when the object has been received and fully initialized, and by `NetworkHost.makeAlive` after loading a state. Sets `enableReplication` by default: define it to do your initialization.
