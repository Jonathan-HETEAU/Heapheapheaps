# hxbit.UID

**typedef** · package [`hxbit`](README.md) · source [`hxbit/UID.hx`](https://github.com/Jonathan-HETEAU/hxbit/blob/ccr-01f70725-tatboj/hxbit/UID.hx)

The unique identifier of a `Serializable` object: an `Int`, or an `haxe.Int64` with `-D hxbit64`. The highest bits store the sequence number (see `NetworkHost`).

Alias for: `Int`
