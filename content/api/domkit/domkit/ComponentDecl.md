# domkit.ComponentDecl

**interface** · package [`domkit`](README.md) · module [`domkit.Component`](Component.md) · source [`domkit/Component.hx`](https://github.com/Jonathan-HETEAU/domkit/blob/ccr-01f70725-tatboj/domkit/Component.hx)

Type parameters: `<T>`

Declares the component of another class `T`: a class implementing `ComponentDecl<T>` (with [`domkit.Object`](Object.md)) defines the properties of `T`, for classes that can't be modified.
