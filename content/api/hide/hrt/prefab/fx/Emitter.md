# hrt.prefab.fx.Emitter

**class** · package [`hrt.prefab.fx`](README.md) · source [`hrt/prefab/fx/Emitter.hx`](https://github.com/Jonathan-HETEAU/hide/blob/ccr-01f70725-tatboj/hrt/prefab/fx/Emitter.hx)

Extends: [`hrt.prefab.Object3D`](../Object3D.md) → [`hrt.prefab.Prefab`](../Prefab.md)

A particle emitter of an FX: emits instances of its child prefab (the particle template) with curves for the parameters (children curves named after the parameters).
